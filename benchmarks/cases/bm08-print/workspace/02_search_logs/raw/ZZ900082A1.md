# ZZ900082A1 挤出机电机电流异常监测方法

- 公开号：ZZ900082A1（虚构）
- 申请人：螺旋挤出技术研究所（虚构）
- 公开日：2021-06-02

[0001] 本发明涉及挤出成形的电机状态监测，尤其涉及按电流纹波判别送料异常。
[0002] 送料不畅与堵料会以电机负载波动的形式提前暴露。
[0003] 在挤出机电机驱动器上取样电流信号，按打印频率段做带通滤波提取纹波。
[0004] 纹波幅值与周期特征构成特征向量，送入预训练分类器。
[0005] 分类器输出正常、断丝、堵料三类判别结果及置信度。
[0006] 判别为断丝或堵料时，本方法仅输出告警信号，由人工停机处理。
[0007] 特征库可随新增样本离线扩充，更新由设备厂商统一发布。
[0008] 本方法不涉及打印层图像或切片比对。
