# ZZ900081A1 打印层图像质量在线检测装置

- 公开号：ZZ900081A1（虚构）
- 申请人：增材视效科技公司（虚构）
- 公开日：2020-03-14

[0001] 本发明涉及增材制造过程监测，尤其涉及打印层的图像质量检测。
[0002] 层间缺陷（错位、缺料、翘曲）在打印早期即可从层图像看出。
[0003] 相机支架固定于打印舱顶，对每打印完的一层自动成像。
[0004] 成像触发与打印进度同步：层高计数器每完成一层发出拍照指令。
[0005] 检测主机把层图像与切片软件导出的预览图逐层比对，输出轮廓偏移量与缺陷标记。
[0006] 检出缺陷时装置立即报警并暂停打印，等待操作人员到场处置。
[0007] 层图像按时间顺序存档，供事后追溯。
[0008] 本装置不采集挤出机电机信号，也不执行任何自动回退打印。
