# ZZ900031B1 城市道路车道分配系统

- 公开号：ZZ900031B1（虚构）
- 申请人：通衢智慧交通股份公司（虚构）
- 授权日：2017-05-23

[0001] 本发明涉及城市道路交通控制，尤其涉及社会车辆的车道级分配。
[0002] 城市主干道在高峰期出现车道级不均衡拥堵，部分车道排队过长而相邻车道空闲。
[0003] 路侧单元采集各车道的车流速度与排队长度，形成车道拥堵度指标。
[0004] 中央子系统接收车载终端上报的目的地信息。
[0005] 系统按预计行程时间最短为目标，为每辆请求车辆分配行驶车道。
[0006] 分配结果经路侧可变信息标志或车载终端下发，车辆按指引变更车道。
[0007] 当某一车道的实时拥堵度超过阈值时，系统将后续请求车辆优先分配至相邻较空车道。
[0008] 交叉路口仍沿用固定配时信号灯控制，本发明不涉及路口通行权管理。
[0009] 本发明面向城市社会车辆，不适用于封闭园区内的自动导引车辆。
