# ZZ900034A1 机器人集群任务重分配方法

- 公开号：ZZ900034A1（虚构）
- 申请人：群力智能装备研究院（虚构）
- 公开日：2021-07-06

[0001] 本发明涉及机器人集群的容错调度，尤其涉及节点失效后的任务接管。
[0002] 集群中的作业机器人执行分拣与搬运任务，单台失效会造成其任务积压。
[0003] 每台机器人向控制节点周期上报心跳与自身任务队列。
[0004] 控制节点在连续丢失心跳后判定该机器人失效。
[0005] 控制节点读取失效机器人的任务队列，将其中未完成任务取出。
[0006] 未完成任务按优先级排序后，重新分配至当前任务量最少的在役机器人。
[0007] 重分配完成后，控制节点向全部在役机器人广播新的任务分配表。
[0008] 失效机器人恢复上线后，加入集群末位等待新任务，不自动收回原任务。
[0009] 本方法不限定机器人的移动方式，适用于轮式、履带式与轨道式集群。
