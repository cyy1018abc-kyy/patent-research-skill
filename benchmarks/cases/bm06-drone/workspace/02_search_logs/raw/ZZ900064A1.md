# ZZ900064A1 舞台灯光音乐节拍同步控制系统

- 公开号：ZZ900064A1（虚构）
- 申请人：声光演绎装备有限公司（虚构）
- 公开日：2018-12-06

[0001] 本发明涉及舞台演艺灯光控制，尤其涉及灯光效果与音乐节拍的同步。
[0002] 人工对拍的方式在快节奏曲目中难以保证灯效与鼓点一致。
[0003] 控制系统导入曲目的节拍时间轴，节拍点由离线节拍分析或人工标记得到。
[0004] 灯光素材库中每条灯效标注其持续时长与适配节拍型。
[0005] 时序引擎按节拍时间轴排布灯效队列，使每次灯光颜色与亮度变化落在节拍点上。
[0006] 现场音频分析器实时校正节拍相位，允许乐队即兴时的动态跟随。
[0007] 输出协议为标准舞台灯光控制协议，面向地面灯架、摇头灯与 LED 屏。
[0008] 本系统不涉及任何飞行器或空中平台。
