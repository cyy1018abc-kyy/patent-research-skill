# ZZ900043A1 识别模型的人工回流标注系统

- 公开号：ZZ900043A1（虚构）
- 申请人：众智数据服务有限公司（虚构）
- 公开日：2021-05-11

[0001] 本发明涉及识别模型的持续改进系统，尤其涉及低置信样本的人工回流标注。
[0002] 上线模型对长尾样本的识别置信度偏低，仅靠离线重训难以针对性提升。
[0003] 本系统在推理服务侧挂接置信度旁路，持续筛选可疑输出。
[0004] 旁路按预设门限过滤：置信度低于门限的输出被截留，原文区域截图一并保存。
[0005] 截留样本进入人工标注队列，标注员在标注界面上给出正确结果并提交。
[0006] 已标注样本写入增量训练集，触发模型的增量更新任务，更新后自动回归测试。
[0007] 队列按样本类别聚合，同类样本攒批下发以降低标注切换成本。
[0008] 系统与具体识别模型解耦，任何输出置信度的模型均可接入。
