# ZZ900041A1 多模板匹配票据识别方法

- 公开号：ZZ900041A1（虚构）
- 申请人：文通信息处理研究所（虚构）
- 公开日：2018-04-17

[0001] 本发明涉及光学字符识别，尤其涉及票据类版式固定文档的识别方法。
[0002] 票据图像倾斜、油墨深浅不一，直接整页识别的错误率难以接受。
[0003] 本方法先做版面分析，再逐字段识别，最后统一校正。
[0004] 版面分析采用水平与垂直投影：对二值化图像按行、列统计墨点密度，投影谷点即文本行与列的边界，据此切出单行文本区域。
[0005] 单字区域送入模板匹配器：与预存字模逐一比对，按相似度打分并输出得分最高的若干候选字及对应分值，分值即该候选的置信度。
[0006] 识别结果按字段拼接后送入领域词库匹配：命中词条的字段按词库校正，未命中的保留原识别结果。
[0007] 词库覆盖银行、税务等十二类票据的高频字段，词库可由维护人员定期更新。
[0008] 实测在本所票据测试集上，字段级准确率较整页识别提升约两成。
[0009] 本方法不依赖任何联机服务，可在离线一体机上运行。
