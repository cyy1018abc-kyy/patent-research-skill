# ZZ900021A1 分布式电池均衡器

- 公开号：ZZ900021A1（虚构）
- 申请人：蓄能电源系统有限公司（虚构）
- 公开日：2019-11-14

[0001] 本实用新型涉及串联电池组的均衡装置，尤其涉及被动均衡的电路结构。
[0002] 串联电池组中各单体容量不一，长期循环后出现容量离散，需对高压单体进行旁路泄放。
[0003] 每个电芯并联一条均衡支路，支路由均衡电阻与旁路开关串联构成。
[0004] 采样板上设有电压采集通道，控制器按轮询次序依次读取各串联电芯的端电压。
[0005] 控制器每五十毫秒完成一轮全部电芯的电压巡回采样，并将结果存入循环缓冲区。
[0006] 当某电芯端电压超过组内均值预设余量时，控制器开启该电芯的旁路开关进行泄放。
[0007] 泄放均衡在充电与放电的全过程均可执行，不受充电阶段限制。
[0008] 均衡电阻的泄放占空比固定为二分之一，以平衡泄放速度与电阻发热。
[0009] 均衡电阻贴近电芯布置，热量经印制板铜箔自然散失。
