# ZZ900093A1 防火疏散门机械优先开启装置

- 公开号：ZZ900093A1（虚构）
- 申请人：安逃门控工程公司（虚构）
- 公开日：2021-02-18

[0001] 本实用新型涉及疏散用门的开启装置，尤其涉及机械优先于电控的开启保证。
[0002] 疏散门在火灾断电或电控失灵时必须保证机械开启万无一失。
[0003] 门内侧设水平推杆，推杆经离合机构与门闩直连。
[0004] 电控锁体平时锁闭门闩，授权信号或门禁系统可驱动解锁。
[0005] 无论电控处于何种状态，人力推动推杆都经离合机构直接拉开门闩。
[0006] 离合机构为纯机械件，断电、死机、电机卡死均不影响推杆开锁路径。
[0007] 推杆动作触发疏散报警，向楼宇系统上报开门事件。
[0008] 本装置针对公共疏散门，不考虑住宅门锁的指纹、远程开锁等电子功能。
