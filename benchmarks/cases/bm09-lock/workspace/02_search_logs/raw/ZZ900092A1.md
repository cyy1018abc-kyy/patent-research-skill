# ZZ900092A1 按压唤醒一体式移动终端

- 公开号：ZZ900092A1（虚构）
- 申请人：掌芯移动设备公司（虚构）
- 公开日：2019-09-03

[0001] 本实用新型涉及移动终端的传感复用，尤其涉及按压与指纹识别共用感应区。
[0002] 手机侧边框集成了电源键与指纹传感器的双重部件，占用空间且成本高。
[0003] 本终端把压感层与指纹传感层叠合在同一感应区内，形成一体化模组。
[0004] 压感层检测到按压动作时立即上电指纹传感层，无需独立的唤醒按键。
[0005] 一体化模组布置在终端侧框，手指自然握持即可完成按压加识别。
[0006] 压感阈值可校准，避免口袋内挤压造成的误唤醒。
[0007] 唤醒后指纹识别通过即解锁屏幕，失败则转入密码输入。
[0008] 本实用新型面向手机、平板等移动终端，不涉及门锁或门禁结构。
