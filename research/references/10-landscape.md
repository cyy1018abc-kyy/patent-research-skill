# 10 · 技术态势报告（patent_intel 扩展，可选）

> **使用边界（最重要）**：态势报告是**描述性统计**，对象是"本次检索拿到的样本"。
> 聚类稀疏、年度低谷、某申请人缺席——都只说明样本长这样，**不能证明技术空白**，
> 更不能推出可授权结论。要证明"空白"，需要负责任的全库普查（如内核 G-S-04 的
> 引证/同族普查链路），而不是本报告。

## 生成

```bash
python -m patent_intel landscape report --root <ws>   # 写入 sidecar reports/
```

输出本地 CSV + Markdown，无 JS、无外部依赖、可重现（同输入同输出）。

## 怎么读

| 输出 | 含义 | 不能读成 |
|---|---|---|
| 申请人表 | 样本内家族数/文献数（分开计） | "某领域谁最强" |
| 年度趋势 | 样本内公开年分布（缺失年份显式计入） | 行业景气度 |
| 技术轴分布 | 我们在哪些轴上检索到了东西 | 技术热点的全景 |

## 采样偏差披露

报告页眉固定披露：样本量、未知家族占比、年份缺失占比。检索样本稀疏时，
结论措辞必须保留"样本内"限定语；对外的正式文件引用本报告前需要人工复核
检索式的覆盖面（配合 recall report 的缺口清单）。
