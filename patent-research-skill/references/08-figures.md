# 08 附图规范与标记校验

> 对标：cnipa-patent-kit 的 figure-drawing + 附图标记双向校验；实现于 `patentkit figures`（内核 0.3.0）。

## 中国专利附图的硬性要求（cponline 上传口径）

- **黑白线条图**：不得用灰度/彩色/照片（照片仅在必要时附于说明书后）；
- **300 DPI** 以上分辨率（矢量 SVG 转 300DPI 黑白位图即可）；
- 部件用**阿拉伯数字标记**（10、20、31…），全文与图一致；
- 图中**不得有多余文字**（除必要的关键词，如流程图的「是/否」）；
- 说明书中「图 1」「图 2」的编号与附图页顺序一致。

## 标记双向一致性（V033）

两个高频翻车点，工具按 warn 拦截（文字抽取是启发式，**只提醒不自动改**）：

1. 说明书提到标记 **32**，图里只有 30、31 —— 细则「清楚」问题；
2. 图里画了某部件，正文从未描述 —— 读者无法图文对应。

```powershell
# 图规格放在 07_drafting/figures/*.figure.yml：
# figure: FIG-1
# title: 系统框图
# parts:
#   - {id: "10", name: 电解槽}
#   - {id: "20", name: 分离器}
# connections:
#   - {from: "10", to: "20", label: 循环液}

python -m patentkit figures check      # 双向核对（V033 warn）
python -m patentkit figures draw FIG-1 # 生成确定性 SVG 框图（离线、无依赖）
```

SVG 是矢量的、完全离线生成；提交前在本地转 300DPI 黑白位图（内核不为此引入重依赖）。

## 规格文件约定

- 一个图一个 `*.figure.yml`，`figure` 字段是图的 ID（FIG-1…）；
- `parts[].id` 是附图标记（字符串数字），`name` 是部件中文名；
- `connections[]` 描述框图箭头（from/to 用标记 id），`label` 可选；
- 手绘的复杂结构图不必用工具生成，但**规格文件仍要建**——校验靠的是规格，不是图片本身。

## 边界

- V033 是 **warn**：正则抽取的「部件名+数字」可能误伤（如「步骤3」不匹配，但别的场景可能）。
  告警必须人工对图复核后再动，规则永不自动删标记。
- 附图只是底稿的一部分；**不构成法律意见**，提交前由代理师复核。
