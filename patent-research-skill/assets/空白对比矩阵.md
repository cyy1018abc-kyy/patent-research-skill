## 每列（每篇对比文件）的输出

```text
D1 — <标题>  <公开号或 URL>
- 申请人: <applicant>
- 公开年: <year>
- 命中轴: N<n>, N<m>
- 关系: □ blocking（阻挡新颖性） / □ 部分重叠 / □ 边缘
- 关键片段: <引用原文 1–3 段，必须可回溯到 raw/ 或原文>
- 差异点: <我们的区别特征 / 对方未公开之处>
- 证据等级: verified（有 raw/） / attested（有 sha256 绑定） / asserted（仅自述）
```

## 三层判定（填表时同步写）

| 层 | 问什么 | 结论 | 依据（证据等级） |
|---|---|---|---|
| 第一层：单篇新颖性 | 是否有单篇覆盖**全部**核心特征？ | 成立 / 存疑 / 不成立 |  |
| 第二层：组合创造性 | 2–3 篇组合是否「显而易见」？是否存在无法拼出的零披露原子？ | 成立 / 存疑 / 不成立 |  |
| 第三层：技术效果 | 是否存在非显而易见、且必须以区别特征为前提的效果？ | 成立 / 存疑 / 不成立 |  |

> 第二层必须写**自我攻击**：列出审查员最可能的组合动机与反驳，再写应对。
> 三层结论都要带证据等级；没有 `raw/` 支撑的判断只能是 `asserted`。
