# Sample data (synthetic; for demonstrating fields only)

> ⚠️ The data here is **fabricated placeholder values**, used only to demonstrate "what a candidate list should look like".
> **Do not** treat it as search evidence, copy it into a real workspace, or base any conclusion on it — it has no `raw/` support,
> so in a real process it can only count as `asserted`.

| File | Purpose |
|---|---|
| `candidates_example.json` | One synthetic candidate, showing the fields and evidence-level notation of `03_candidates/` |
| `search_log_example.json` | One synthetic search log, showing the `raw/` reference and the `capture_mode` field |

Usage: read them against the collection discipline in `references/01-search-framework.md` and the field conventions in the workspace's `03_candidates/README.md`,
to understand the chain "log → raw/ → candidate → gates" — not to copy the content.

In a real workspace, candidates are generated by `patentkit ingest` from `raw/` raw responses, never written by hand.
