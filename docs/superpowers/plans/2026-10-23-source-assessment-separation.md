# 来源等级与判断状态分离 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking。本任务在当前会话执行。

**Goal:** 落实已确认的决策：AI 可参与 G-S-02，G-S-03 必须有绑定具体判断内容的有效人工确认。

**Architecture:** 来源继续使用 evidence_level；判断在 patentkit 内核独立记录，技能脚本仅调用 API。内核源码来自公开 Release 的 patentkit-0.1.2.tar.gz，SHA-256 为 5ab1ff6e6387c1b6f30e8e084b0da88d93bf71426e9cb901158562d9b52aae14，保留在相邻 patentkit/ 目录，技能仓库不混入内核副本。

**Tech Stack:** Python ≥3.11、现有 jsonschema/PyYAML/pytest、Git；新增源码注释使用中文，文件保持 UTF-8。

## 已确认规则

1. evidence_level 只描述来源。AI 评分不降低真实检索来源，人工确认不提高来源等级。
2. G-S-02 接受 AI 双维评分；摘要或正文均可，但问题、手段分别需要原文片段、位置与理由，缺失时不计入。按技术轴核对依据。
3. G-S-03 接受明确 ID 名单的批量人工确认，逐篇记录确认人、时间和判断指纹。
4. 评分、角色、技术特征映射、理由、支撑原文等实质变化使确认失效；无关元数据修正不影响确认。
5. 人工判断优先。AI 新意见进入建议记录，不覆盖已有人工评分或排除决定。
6. 保留历史。缺少判断来源或人工确认的历史记录，不推定为已确认。

## 范围与文件

- 内核 assessment.py：共享判断、原文定位、指纹、批量操作，规则实现一次。
- 内核 gates.py：G-S-02 核对判断依据；G-S-03 核对有效人工确认；保留数量阈值和来源三列。
- 内核 review.py、api.py：接通 JSON 判断、确认、迁移、导出指纹；旧 CSV 入口不得绕过规则。
- 内核 validate.py、候选 schema、模板词汇表：判断校验与保守迁移提示。
- 内核版本、README、独立回归测试：兼容边界、wheel/sdist 构建。
- 技能 SKILL.md、references/03、04、05、模板、示例、README：统一来源/判断口径。
- 技能 _env.py、CI：拒绝缺少新协议的旧内核，防止旧逻辑报告新规则 PASS。
- 不处理搜索经验规则和整套发布重构；不修改真实材料，不推送或发布。

## 指纹与信任边界

指纹包含候选身份/目标/轴、双维评分、角色、新颖性标记、理由、技术特征映射、原文定位及定位内容。原文限工作区内 UTF-8 文件：JSON 使用 JSON Pointer，文本使用行范围，引用必须匹配原文。只定位摘要正文时，无关作者字段变化不影响指纹。工具核验引用与记录的一致性，不证明语义判断正确，也不能认证调用者确为自然人。
