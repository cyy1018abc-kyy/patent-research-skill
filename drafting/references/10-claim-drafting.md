# 10 权利要求撰写（底稿级）

> 前提：已走完 [09](09-disclosure-drafting.md) 的前置条件。产出是**底稿**，代理师复核后才能用。

## 独权：把「零披露原子」写进前序之后

三层判定（见 [00 前置纪律](00-prerequisites.md)）第二层找出的**零披露原子**——任何 D 列
组合都拼不出的特征——是独权的核心。写法：

- 前序部分：与最接近 D1 共有的特征（背景技术对应）；
- 特征部分：「其特征在于」+ 区别特征（零披露原子 + 必要支撑特征）；
- 每个特征都要能在 support_mapping_table 里指到说明书段落。

## 从属权项的层次设计

1. **数值层**：上位概念（独权）→ 数值范围（从权）。范围必须落在溯源登记（A 级实测）
   与说明书披露之内——超范围是最危险的缺陷，答复救不回；
2. **替换手段层**：对每个关键手段给 1–2 个替代实现（防止绕过）；
3. **场景层**：应用场景限定（车用/航空…，对应检索的应用场景子查询）。

从属权项三问：挂在哪个独权下？附加特征是否矛盾？有没有支持段落？

## 数值范围自检（最容易翻车）

| 检查 | 工具 |
|---|---|
| 权项数值 ⊆ 说明书披露范围 | `claims/numerical_consistency_check.md`（见 [00 前置纪律](00-prerequisites.md)；核对面板在 research 技能 06 号文档） |
| 每个数值有 A/B/C 来源 | `patentkit provenance check`（V031/V032） |
| C 级（示例值）显式声明 | 溯源登记的 note 字段 |

## 改稿纪律

多轮改稿走 [13-改稿闭环](13-revision-loop.md)：补丁 → 变更日志 → 重过门。
**禁止顺手改无关内容**——任何实质变更都会使相关人工确认失效（指纹变了），
需要重新确认。

## 领域专项形态（2025 指南口径）

通用纪律之上，特定主题有各自的**权利要求形态**与**绑定要求**，撰写前先对号入座：

### AI / 软件 / 算法（指南二·九 §2、§5.2、§6）

- **四位一体布局**：方法 ＋ 装置 ＋ 计算机可读存储介质 ＋ 计算机程序产品。与程序流程各步骤
  完全对应的装置权利要求应理解为**程序模块构架**（不是硬件实体）；程序产品理解为软件产品；
- **客体三要素自查**（§2）：解决技术问题 + 遵循自然规律的技术手段 + 符合自然规律的技术效果，
  三者齐备才是法 2.2 的技术方案。三条授权路径速查（§6.1.3）：①算法处理技术领域中具有确切技术含义的数据；
  ②算法与计算机系统内部结构特定技术关联（减少存储/传输量、提高处理速度）；
  ③具体领域大数据挖掘符合自然规律的内在关联；
- **算法特征必须与技术数据绑定**：至少一个输入参数及其输出与技术领域的具体数据对应关联——
  悬空的算法特征 = 客体（法 25/2.2）与公开不充分（26.3）双重风险；
- **创造性计入口径**（§6.1.4）：「功能上彼此相互支持、存在相互作用关系」的算法/商业特征整体考虑——
  应用于具体技术领域解决具体技术问题、改进计算机内部性能、商业规则实施需要技术手段调整改进，三者居其一；
- **比特流**（§7）：以编码方法独权为基础，引用式撰写存储方法/传输方法/存储介质权利要求；
- 零披露原子纪律不变：算法改进点也要落到特征原子表与 support_mapping_table。

### 化学 / 组合物（指南二·十 §4；展开版见 [19](19-chemistry-practice.md)）

- **开放式 vs 封闭式**：「含有/包含/主要由…组成」与「由…组成」对新颖性结论相反，选型前想清楚；
- 含量禁用「大约/左右/近」，不允许「>X」表述；各组分百分数之和＝100%；
- **医药用途写制药方法类型**：「化合物 X 在制备治疗 Y 病的药物中的应用」——给药对象/方式/途径/
  用量/时间间隔等用药过程特征不具限定作用，别指望它们撑保护范围。

### 生物（指南二·十 §9）

- 序列主题：≥10 个核苷酸或 ≥4 个 L-氨基酸须提交序列表电子文件（说明书单独部分）；
- 基因权利要求六方式：碱基序列 / 编码氨基酸序列 / 参见序列表 /「取代缺失添加＋功能」（须例举衍生蛋白）/
  严格条件杂交＋功能（须详述条件）/ 功能兜底；
- 单抗：六个 CDR 的 SEQ ID NO 或杂交瘤保藏号限定；已知抗原＋仅用抗原限定无创造性；
- **保藏**：公众不能得到的生物材料必须保藏，保藏+存活证明至迟申请日起 4 个月
  （期限已入 `patentkit deadlines` 的 `biological_deposit` 预设）。

## 边界

- 不判断授权前景；不写「本权利要求稳固」这类承诺；
- 功能性限定期慎用：写「用于……的装置」时确认说明书有对应结构支持；
- 撰写权项时引用的每篇对比文献必须来自证据账本（`patentkit ledger`），V034 会拦编造引用。
