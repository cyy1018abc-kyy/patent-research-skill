# English reference set of the patent-drafting skill (courtesy mirror)

The **Chinese files under `../references/` are the authoritative edition**. The files here
mirror them for bilingual users and terminology cross-checking
(`evals/check_terminology.py` pairs both sides and extends the shared anchor list).

- `SKILL.en.md` — mirror of the (Chinese) `../SKILL.md`
- `00-prerequisites.md` — self-contained summary of the research-side discipline
- `09-disclosure-drafting.md` … `13-revision-loop.md` — mirrors of `../references/09…13`
- `glossary.md` is intentionally NOT mirrored: it is itself the zh⇄en mapping (one shared
  copy per skill, byte-identical, CI-enforced)

Translation status: complete for the drafting skill since 3.0.1, and for the research
skill's references 01–08 since 3.1.0 (`research/references.en/`).
