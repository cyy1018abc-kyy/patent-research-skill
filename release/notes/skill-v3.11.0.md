# Patent Research Skill 3.11.0（化学与材料领域 reference；kernel 0.10.0 延续）

Requires **patentkit 0.10.0, assessment protocol 1**, Python 3.11+。内核本轮**无变化**
（0.10.0 延续，无需重装内核）。扩展 `patent_intel` 0.1.0 延续（未变，无需重装）。

## 什么变了

- **新增 `drafting/references/19-chemistry-practice.md`（中英镜像）**——化合物、组合物、
  材料、医药用途类主题的领域专项参考，口径全部引自《专利审查指南》2025 版第二部分
  第十章（章节号引用）：
  - 充分公开三件套（确认/制备/用途效果，含效果数据测定方法、补交实验数据口径）；
  - 权利要求形式（化合物表征、组合物开放式/封闭式相反的新颖性结论、含量规则、
    医药用途制药方法句式与给药特征不具限定作用）；
  - 新颖性/创造性口径（属/种破坏方向、数值范围与共同端点、参数表征推定、
    电子等排与预料不到效果）；
  - 马库什单一性（共同性能+共同结构）与检索侧注意事项。
  本篇是 10 号「领域专项形态」化学速查的展开版，两者口径一致、互链。
- **接线**：两个 SKILL.md（中英）description 增加触发短语「组合物权利要求」「马库什」
  「医药用途」；参考文档表新增 19 号行；evals 38 → 40 用例（D15 组合物含量/开放式
  封闭式、D16 医药用途句式）；术语守卫配对清单纳入 19 号（`check_terminology.py`）。
- 3.10.0 的 2025 指南口径适配内容全部延续；内核期限预设（0.10.0）不变。

## 安装与迁移

安装器清单、manifest schema 2、双 zip 结构不变。已有用户：内容更新，重装技能包即可；
内核与扩展均无需重装。规则表 V001–V038 不变，评估协议 1 不变。

## 边界（与上一版一致）

- 本技能产出底稿与判定辅助，不构成法律意见；不预测授权；
- 期限工具是提醒台账，法定期限以官方发文/通知书为准；
- CNIPA XML 官方格式仍未实现（`official_format_status` 维持 `not_attempted`）。
