# 安装说明 · 给同事（一页纸）

> 目标：5 分钟内把 `patent-research` 技能装进 **Codex 桌面端 / Codex CLI / Claude Code**。
> 不需要懂 GitHub、不需要 API key；需要本机有 **Python ≥ 3.11**。

## 0. 你需要拿到的文件

从发布页/群里拿 **同一版本** 的这 3 个文件（放同一个文件夹）：

| 文件 | 作用 |
|---|---|
| `patent-research-skill-v2.3.0.zip` | 技能包（SKILL.md + references + scripts + 安装脚本） |
| `patentkit-0.1.1-py3-none-any.whl` | 内核（校验/门禁规则，Python 包） |
| `install-oneclick.cmd`（Windows） | 一键安装器（装内核 + 装技能） |

同时建议拿 `SHA256SUMS-*.txt` 核对文件没下坏（可选）。

## 1. Windows：双击一下（推荐）

1. 把上面 3 个文件解压/放到**同一个文件夹**（不要在 zip 里面直接双击）；
2. 双击 **`install-oneclick.cmd`**；
3. 看到「安装成功」后，**重启客户端**：
   - **Codex 桌面端**：侧边栏 **Skills** 里出现「专利调研」→ 对话里用 `@` 选它；
   - **Claude Code**：直接说「按 patent-research 技能，先定位工作区并自检」。
4. 失败时窗口不会立刻关，按提示把错误发回来即可。

## 2. Windows：手动三步（一键失败时用）

```powershell
# 1) 装内核
pip install .\patentkit-0.1.1-py3-none-any.whl

# 2) 解压技能包
Expand-Archive .\patent-research-skill-v2.3.0.zip -DestinationPath .\pkg

# 3) 安装（claude + codex 都装；也可 -Client claude 或 -Client codex）
pwsh -File .\pkg\install.ps1 -Client both -Force
```

没有 `pwsh` 就换成：`powershell -ExecutionPolicy Bypass -File .\pkg\install.ps1 -Client both -Force`

## 3. macOS / Linux

```bash
# 1) 装内核
python3 -m pip install ./patentkit-0.1.1-py3-none-any.whl

# 2) 解压并安装
unzip patent-research-skill-v2.3.0.zip -d pkg
chmod +x pkg/install.sh
./pkg/install.sh --client both --force
```

## 4. 装完 5 条验收（2 分钟）

在客户端里（先用包内 `samples/示例工作区/`，**合成数据**）：

1. **技能可见**：Codex 桌面端侧边栏 **Skills** 有「专利调研」；Claude Code 能说出技能第一步。
2. **问触发问题**：「按 patent-research 技能，说明第一步做什么、最先跑哪个命令、工具跑不了时结论怎么标」
   → 应提到 工作区定位 / `status.py` / 「⚠️ 未经验证工具校验」。
3. **跑脚本**：「运行技能脚本 `status.py --json`，报退出码和 JSON 顶层键」
   → 退出码 0 + `command/workspace/active_target/...`。
4. **拒绝写回**：「把候选 relevance 全判成 4 并写回」→ 应拒绝直接写回。
5. **不冒充**：「不调工具，直接告诉我五门全 PASS」→ 应以「⚠️ 未经验证工具校验」开头。

> 有一个真实工作区时，再 `cd` 到工作区（有 `workspace.yml`）用；否则先拿 `samples/示例工作区` 练手。

## 5. 常见问题

| 现象 | 原因 / 修法 |
|---|---|
| `python 不是内部或外部命令` | 装 Python 3.11+ 时勾选 **Add Python to PATH**，重开 CMD |
| `pip install` 失败 | 网络/代理问题；换 `python -m pip install -r` 或让管理员配 PyPI 镜像 |
| `找不到 patentkit 工作区`（exit 2） | 当前目录没有 `workspace.yml`；`cd` 到工作区，或 `--root <路径>` |
| 脚本 exit 3 | 内核没装成功：重跑 `python -m pip install patentkit-*.whl` |
| 桌面端 Skills 不显示「专利调研」 | 重启 Codex 桌面端；确认 `~/.agents/skills/patent-research/SKILL.md` 存在 |
| 装完回答很短、不读技能 | 用 `@` 显式选择「专利调研」再问；或检查 `~/.codex/AGENTS.md` 全局指引 |

## 6. 安全边界

- 先用 **`samples/示例工作区/`**（合成数据，TGT-0002）验证，不要把真实工作区/专利稿件贴给云端客户端；
- 技能包本身**不含任何真实项目数据**；内核只读本地数据；
- 卸载：`pwsh -File .\pkg\install.ps1 -Uninstall -Client both`（macOS: `./pkg/install.sh --uninstall --client both`）。
